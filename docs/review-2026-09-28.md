- 原轉錄器在字串與註解上直接施行正則替換，且改寫 import 時無法保留複數引入、相對路徑與 future imports。現以符節位置改動原文，代理體保存可逆改動紀錄，整庫閱覽體保存名稱對照與位置。

- 逐字還原要求保留封卷與完整碼卷；修改碼卷時拒絕還原，舊式沒有完整碼卷的駢文須重新產生。單卷正文修辭可以修改；整庫封卷另驗證整份輸出。
